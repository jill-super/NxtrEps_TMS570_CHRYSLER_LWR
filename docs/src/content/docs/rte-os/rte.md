## Usage

Application code uses only the generated `Rte_*.h` APIs (`Rte_IRead_*`, `Rte_IWrite_*`, `Rte_Call_*`, `Rte_Call_..._CheckpointReached` for WdgM supervision). To change interfaces, edit the DaVinci composition and regenerate; per-component `RteGen.bat` scripts under each module `tools/` drive the contract generation used by unit tests.
